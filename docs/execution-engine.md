# 执行层契约

状态：当前实现。入口为 src/execution/executor.ts，工具契约版本 25。

## 分工与生命周期

src/agent/policy.ts 提供探索政策；上下文和模型传输位于 src/agent/context 与 src/agent/model。执行器组装 Mastra 工具并推进运行；工具 schema 集中于 tool-inputs.ts。run-queue.ts 管理串行队列、取消和待核对锁；run-manager.ts 管理持久记录。HTTP 路由不再组装领域报告，报告位于 src/server/reports。

运行先持久化 queued，再启动浏览器。执行状态、业务结果和检查结论分别保存。业务成功、预期拒绝、未知业务结果与检查阻断可以有不同组合；模型调用正常返回不意味着任务完成。

阶段跟踪限制最后阶段的新探索。run_finish 使用短输入，由执行器根据持久事实生成完整结论；未决假设、未完成调查、缺少依据或不可靠证据不能被一句“完成了”覆盖。预算耗尽不会自动转成成功。

## Agent 可调用的能力

| 能力 | 作用与限制 |
| --- | --- |
| page_observe / element_details | 获取当前页面与按需细节；观察版本变化使旧引用失效 |
| page_act | 执行动作，返回结果和后置观察；歧义目标不能随意选第一个 |
| rules_search / rule_details / checks_run | 检索元数据、展开声明、运行适用规则 |
| 路径工具 | 复用有前后置条件的导航片段；条件不成立交回 Agent |
| 时序调查工具 | 一次完成目标绑定、真实采样、结果与证据保存 |
| hypotheses_record / findings_submit | 持久化可复查假设和发现，验证证据引用 |
| history_read / tool_result_read | 分页恢复历史与原始结果，交付给下一轮模型 |
| run_finish | 明确请求结束，由执行器验证并提交 |

`investigation_check`、`rule_check` 与 `findings_submit` 均支持 Agent 声明 `evidenceRefs`。前两者保留自动生成的截图、快照与测量，同时附带经当前 run 归属校验的业务依据；不接受凭空或其他任务的引用。原子调查的复用键包含依据和语义 target，不能用旧结果代替不同依据的新问题。公开资源保留原始响应正文，模型读取预算不足时显式标注截断。

结束时，未知业务结果必须保留恢复及后续路径的未验证范围，即使 Agent 选择了 `scope-covered`。执行层据已记录事实生成报告；不能因为假设已解决而声称业务路径全部覆盖。响应处理按到达顺序排队，观察和结束前有界等待，终态提交后不再接受迟到事实。


具体字段以源码 schema 为准；新增工具需有适用条件、最小必要输入、结构化结果、失败反馈和副作用说明，不向模型暴露内部数据库或评估答案。

工具回执区分执行成功、业务失败、验证失败、超时和未知状态。失败工具结果必须交付到下一轮；发生副作用后不能因模型响应失败就重新执行同一动作。

## 观察和记忆

默认采用紧凑 a11y、页面文本、元素引用；完整详情按需读取。动作后可复用同版本观察，导航、布局与状态变化需重新确认。当前请求保留关键业务事实、持久发现、未决事项和近期工具结果，不能只截断 token 后丢失关键约束。

首包、模型阶段、工具执行、请求总耗时分别计时。工具时间可能处于模型流生命周期内，不能把重叠时间简单相加。失败请求计入次数，缺失 usage 保持未知。

## 原子调查与语义绑定

EXECUTION_ATOMIC_INVESTIGATION 默认开启。Agent 指定调查意图并绑定当前事件/目标；执行层负责一次完成有界真实时间采样，而非让模型每隔数百毫秒重新决策。

调查结果包括时间窗口、样本、证据引用和适用性。缺少触发事件、存在多个合理目标、目标改变、采样受干预时返回 unknown 或拒绝，不扩大解释。当前声明的时间窗口是工具测量契约；尚不等于从所有业务响应时刻起算的通用 SLA。

一次原子调用仍计入原预算，不获得新的动作、模型或时间额度。当前保留 EXECUTION_ATOMIC_INVESTIGATION=0 回退入口。

## 有限阻断审查

EXECUTION_BLOCKER_REVIEW 默认关闭。开启时使用 OpenRouter Decisions API，固定 typesafe/jev-1.13-20260917 已验证快照。该审查复用同一请求/费用预算。

只有阻断证据充分且没有待处理工作时才尝试。页面有恢复机会、复杂或变化中的表面、未知副作用时跳过；服务错误或结论无效则继续完整 Agent。模型仅给建议，执行器重新验证事实版本及恢复入口，再允许 observed-blocker 收尾。它没有通用终结权限。

## 安全执行与可靠持久化

- 单页面和共享业务资源串行；取消中止模型/工具，迟到响应不能再派发动作。
- 总时限、请求时限、工具时限、调用次数和动作次数共同约束。重试仅在现有预算内且未执行副作用时进行。
- 写入权限由当次契约的副作用策略决定，不按按钮文案判断。购物允许购物车准备性写入、只有结账消耗创建额度，订单产生后仍禁止这些写入；导出不声明准备性写入，允许一个实体及其一次被明确允许的重试，重试必须属于该实体。创建额度在请求派发前预留，不等响应回来才计数。未声明写入默认拒绝并记录 `write:denied`。拦截记录包含执行器干预来源，受影响样本不能证明原站点缺陷。
- 未知写结果不自动重放；先等待业务核对。已知 `202` + `processing` 是已接受操作而非未知写入，之后允许公开只读轮询。
- 报告在单个读取事务内组装。结束提交后使用新连接检查终态及事件尾；核验失败进入待核对隔离。
- 重启未完成任务标为 interrupted，不自动恢复业务写入。
- 操作者核对后可使用私有控制 token 调用 POST /api/evaluation/reconcile。核对解除资源锁，不生成成功结论或重放订单。

原数据库异常根因尚未确定，这些保护用于拒绝假完成，不应描述为根因已修复。

## 证据与兼容性

保存原图和红框副本，区域来自实际测量。命中测试只证明指针拦截；像素遮挡或“看起来可点击”需要独立视觉依据。Agent 的假设、调用、结果、版本与覆盖缺口用于复盘漏报，而非只输出最终结论。

证据类型为 `screenshot` / `snapshot` / `measurement` / `resource`。`resource` 是执行器按适配器声明保留的公开业务资源，正文逐字保存，分类信息放在产物元数据（`resourceKind`、`operationId`）而不是包裹正文——这样评分器读到的就是业务自己发布的文档。超出预算时显式截断并标注，不静默丢弃。

未达发布门槛的后台视觉分析运行代码及工具已移除。历史报告的 analysis 记录仍可读取，兼容逻辑仅位于 src/server/reports/legacy-analysis*；Midscene/Qwen 视觉定位仍保留。新运行不再创建后台分析任务。

验证命令与边界见[开发约定](development.md)和[靶场与评估](arena-and-evaluation.md)。


公开产物下载由业务适配器的 `downloadOperation(request)` 声明，执行器只放行同源 GET、属于本轮创建且最新事实为 succeeded 的实体。它是页面点击下载时的窄导航例外，不放开任意 API、源文件、其他实体或私有控制路由；每次重定向仍重新检查边界。购物适配器未声明下载入口，原导航约束不变。
