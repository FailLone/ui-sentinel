# R3：已验证资料短路径复用

## 实现说明（2026-10-12）

固定产品基线 `2f79c50`，独立分支 `codex/r3-path-reuse`。保存完整、健康且证据可核验的匿名资料路径为声明式候选；通过显式 ID 在同一入口 URL、同一资料身份/版本的新运行尝试复用。候选保存来源、原模型语义计划、前置谓词、公开目标描述和结果要求，不保存可在新运行使用的旧 ref、权限或成功证据。

复用沿用 R2 的计划登记、当前 DOM 观察、唯一绑定、原 page_act、原测量和完成证明。程序只接管稳定步骤与标识衔接；不运行任意代码、不复用业务 Journey、不自动发布规则。每步重新绑定真实控件，比较公开结构描述并再次检查前置；新异常记录为本次失败，不能叫缓存失效。来源/目标失效交回原 Agent，列明已发生动作、当前测量和未完成步骤；取消、执行异常与未知结果仍走原停止/恢复契约，不重放动作。

免费验证将覆盖健康保存/复用、真实缺陷、来源版本变化、目标缺失/歧义/替换、前置不满足、取消或未知结果，以及报告恢复。复用现有 R2 页族，所有新测试输入保存在 Git；原始运行材料放 data。固定模型请求差仅证明接线，不能证明真实模型提效。中央 Roadmap 和维护者收尾记录不在本分支修改。
