## 已交付能力

网址加一份文本/Markdown，主Agent提取一条有来源的1–3步匿名本地路径，绑定真实控件及结果节点，执行和测量，再生成要求、动作、证据与未检查范围对应的报告。普通用户不用编写CSS或检查清单。

资料返回后，模型交付草案、带具体查询的缺口、或无法验证说明；程序复用原登记、绑定与完成判定。当前有效绑定提供原动作参数。纠错直接携带相关原文；正文恢复最多两次、累计3000字节的局部调度机会，不扩大总预算。Rule负责质量判定、Skill负责工作方法、程序负责流程和证据，三者不混用。

## 使用与边界

使用已配置主模型的本机环境，构建后启动：

```sh
EXECUTION_URL_SCAN=1 EXECUTION_PRODUCT_SOURCES=1 pnpm start
```

打开 `http://localhost:4111`，选择“网址 UI 检查”，输入网址及产品资料名称、正文。保存runId可恢复查看报告。实际运行可能调用付费模型；本次收尾没有启动服务或新运行。工作台/API及支持范围见[产品资料用法](product-sources.md)。开关默认值未改变。

仍限定一份资料、一条短路径、不同本地click/fill控件及操作前已存在的唯一结果节点。Figma、多文档、登录角色、复杂业务写入、导航路径步骤、任意自然语言全覆盖与动态结果容器后置。两项弃权不能称功能验证通过；整条资料路径成功也不能抵消其他未完成义务。
