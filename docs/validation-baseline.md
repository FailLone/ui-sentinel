## 当前决定与未完成项

采用 Mastra Agent/Tools、Playwright、Midscene/Qwen。默认开启原子时序调查；有限 Jev 阻断审查可选且默认关闭。主 Agent 仍负责探索、语义绑定和复杂收尾。
