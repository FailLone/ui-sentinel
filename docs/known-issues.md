# 限制与已知问题

本页记录仍影响使用或验证结论的边界。当前为受信单机应用；阶段验收不提供无人值守可靠性、任意网站覆盖或服务保障。能力目标见[Roadmap](product-roadmap.md)。

## 支持范围

| 能力 | 当前限制 |
| --- | --- |
| 网址检查 | 默认关闭；匿名、最多3页/深度1，局部选样。登录、写请求/表单提交、上传下载、新窗口、WebSocket、Service Worker 不支持；网络干预后不能用受干预状态证明原站点 pass/fail |
| 产品资料 | 一份文本/Markdown、一条1–3步本地 click/fill 路径；结果节点操作前已存在。多文档、Figma、导航路径步骤、登录角色及复杂业务后置 |
| 路径复用 | 精确入口与来源身份/版本匹配；每步取得新证据。计划安装后失效只读交回，不替换计划或重放；模型额外文字解释未验证 |
| 历史基线 | 仅比较实际到达状态的公开依赖/叶节点事实，不证明脚本、样式、网络或整站相同；每次最多检查20个候选运行，但未承诺大历史性能 |
| 规则 | 有限绘制和语义范围；unknown、不适用、未采样不计 pass。图片保形默认关闭，体验建议不自动判缺陷 |
| 弹窗与并行 | 显式启用；匿名同入口重入、有限几何和观察版本，不能克隆登录会话。专项几何结果不代表普通扫描自动发现或整站覆盖 |

历史失败、费用 unknown、未运行行和原始判定保留在[归档索引](archive/README.md)所指材料中。后续成功不覆盖旧失败，也不抵扣旧未知费用。修改对应边界、扩大支持范围或遇到匹配故障时补定向回归，不自动追加整套付费矩阵。

## 保存故障现场

持久失配时停止新提交，保留隔离状态。尽可能在重启前保存 runId、日志、数据库及存在的 WAL/SHM/journal、截图/产物、事件/报告、版本和配置摘要。活文件复制标记为非原子；不要 checkpoint、清库、换库或清状态绕过隔离。核对副作用后才能使用已有 reconcile 接口解除阻塞，它不会重放或自动回滚。

共享材料先去除密钥与敏感页面内容。原始证据与脱敏副本分开，不能改写冻结原件；缺失材料明确记为缺失。
