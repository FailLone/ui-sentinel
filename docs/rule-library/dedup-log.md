## 相似但保留独立

- **D001 / D002 / D009**：分别检查自身裁切、同屏对象碰撞、装饰边界；对象和正常例外不同。一次事件可同时产生候选，但报告同一实际损害时需按证据聚合，不重复计数。
- **D002 / D003 / D010**：可读性、滚动到达和指针命中采用不同检查方法；像素覆盖不证明事件被拦，屏外不证明永久不可达。
- **D004 / R012 / R005**：比例失真、清晰度和缺资源替代分别需要原图比例、目标显示质量、资源状态与身份证据，不能合成“图标正确”。
- **D005 / R004 / D011**：信息消失、主题适配设计取舍、变量解析合同不同；像素相同不证明 token 相同，像素不同也不证明 token 错误。
- **D006 / R006 / R008**：错误陈述终态是条件式缺陷；缺少足够反馈和视觉不连续需要审查。三点换 spinner（0305/0307）并不支持“加载反馈缺失”。
- **D007 / R009**：选择事实丢失表达与交互暗示难发现不同。可见下划线消失不等于所有选中线索丢失。
- **R001 / R002 / R003**：层级、组件等价和空间分组有不同绑定对象，不合为“UI 应与设计一致”。没有具体问题的“UI incorrect”暂缓。
- **D008 / R011**：图表归属与滚动方向提示不同；不合成“图表清楚”。移除数值标签（0215）不必然违反身份可辨认。
