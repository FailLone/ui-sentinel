# UIK-D010 · 当前允许操作的目标不得被无关层拦截指针

- 类型：缺陷检查规则；主题：交互与弹层。
- 文档修订：1；首次建立：2026-10-08（Asia/Shanghai）。

- 来源摘要：1 条（含 0 条归并摘要；不是独立验证次数）。

## 一句话原则

可见、允许且预期可操作的目标，应能在有效命中区域接收指针操作。

## 适用条件

当前操作许可明确；目标可见且在视口内；无应优先交互的模态层。

## 不适用情形和正常例外

正常禁用；模态背景；页面加载合同允许的阻断；在目标内工作的子元素；单点命中失败不等于整控件失效。

## 可观察的违反条件

覆盖层在有效操作区域拦截指针，且没有合法阻断理由，导致预期操作无法触发。

只有适用事实、目标绑定与违反证据均完整时才可判 fail；缺证不视为通过。

## 如何识别检查对象

绑定当前事件对应的稳定目标及目标子树，结合 hit testing、层叠关系和事件证据，不选同名第一个。 目标引用须来自当前观察；引用过期、同名多目标或操作身份不明时重新绑定或返回 unknown。

## 检查步骤

1. 确认当前操作允许，排除模态/禁用/过期目标。
2. 采样合理命中区域并检查最上层元素与目标子树关系。
3. 在安全测试环境核对事件接收；输出被采样范围的结论。

允许事实、当前元素引用、视口、命中点/拦截层及事件。目标歧义、仅变暗或单点证据时 unknown 或限定为采样点问题。 本批只有二次整理的文字报告，未观察真实 UI，未取得截图/设计附件；因此来源记录不能直接产生实测 pass/fail。
