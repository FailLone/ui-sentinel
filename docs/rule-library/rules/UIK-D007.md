# UIK-D007 · 已选中状态应持续有可识别表达

- 类型：缺陷检查规则；主题：交互状态。
- 文档修订：1；首次建立：2026-10-08（Asia/Shanghai）。

- 来源摘要：2 条（含 0 条归并摘要；不是独立验证次数）。

## 一句话原则

用户需要知道当前选择时，选中状态不应因悬停或初始化遗漏而失去表达。

## 适用条件

可信选择事实已建立；单选/页签/筛选结果与当前目标对应；用户需要该状态定位。

## 不适用情形和正常例外

合法取消选择；异步尚未确定默认项；下划线换成其他明确线索；纯 hover 样式无需持续。

## 可观察的违反条件

实际选择保持不变但所有有效选中线索消失，或实际默认选项已经生效却无相应标记。

只有适用事实、目标绑定与违反证据均完整时才可判 fail；缺证不视为通过。

## 如何识别检查对象

按 tablist、单选组或筛选控件的语义与选中事实识别目标，使用当前引用，不按“1W”等文本认定默认。 目标引用须来自当前观察；引用过期、同名多目标或操作身份不明时重新绑定或返回 unknown。

## 检查步骤

1. 确认真正生效的选择与其状态表达。
2. 执行初始化、悬停、移开等不改变选择的动作。
3. 比较视觉线索与语义状态，排除替代标识。

## 所需证据与不确定性

状态事实、前后画面、可访问状态及替代线索。仅下划线消失但仍有背景高亮时不应 fail；不知真实默认值时 unknown。 本批只有二次整理的文字报告，未观察真实 UI，未取得截图/设计附件；因此来源记录不能直接产生实测 pass/fail。
