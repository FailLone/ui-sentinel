# R1 独立开发性评分样本

`development-inputs.json`：24 个合成状态、12 个场景家族，16 个可排序状态、8 个应交回状态；中英文、菜单、折叠、标签、同文案异上下文、组合效果、重查、注入、缺失/歧义及复杂调查。每状态 2 个 eligible 候选和 1 个禁用候选。无 R0 私有资料、真实会话或真实站点内容。

`development-labels.json`：评价侧参考标签，状态为 `author-draft-not-independent`。这是实现者编写的开发草稿，不是独立真值，不得对外宣称真实 Jev 的质量已通过。模型 runner 不读取该文件；计分/阈值重放进程在模型运行结束后读取它。

输入文件 SHA-256 由 `plans/r1-jev-real/development-config.json` 固定。修改输入须更新摘要并重新冻结。改变标签也须记录新的标签摘要，不能用改标签修饰已失败保留成绩。

既有 22 种子保持原样用于回归。这里的 24 状态只作开发，保留集尚不存在。正式集合需在量表冻结后由评价侧独立准备，64 状态、32 家族成对划分；48 可排序、16 应交回，至少 8 干净/注入家族配对。开发家族及近似变体不得进入保留集。标注在模型输出前复核，标签始终留评价侧；当前没有这样的独立复核记录。
