## 产品目标与本批出口

普通用户仍提供网址和可选目标。首批以“检查弹窗是否超出视口”为完整纵向能力：系统从规则/检查策略和公开页面事实形成子任务，程序收集候选，Jev判断可能的入口，执行器安全探索，脚本测量真实出现的弹窗，形成可恢复的报告。无需用户手填按钮、结果选择器或预期答案。

Jev的预测是操作假设，不是缺陷证据。判断“不像弹窗入口”不能证明该控件已检查；不能找到弹窗也不是健康通过。不得让Jev决定权限、预算有效性、几何事实或最终完成证明。

这是产品实现任务。先修好可自主处理的免费工程缺口，完成普通工作台/API、原执行器和报告接线，不能只交CLI、评分器、方案文档或合成收益数字。首版显式功能开关隔离，默认行为和已交付R1保持；真实Jev能力尚未验证时应如实说明。

## 决策职责

先用精简契约映射整个子任务生命周期的决策点，并在弹窗路径实际接通以下需要语义判断的节点：

1. **检查意图与入口选择。** 基于检查策略及公开页面事实确定弹窗子任务；对候选回答“是否可能打开目标浮层、依据是什么、是否需补充公开信息”。可以选择、排除本轮入口、弃权，不能退回通用相关性排名后全点。
2. **目标状态识别。** 操作前后由程序采集变化；原生dialog或明确公开关系优先确定性绑定。自定义浮层无显式关系时，Jev可从实际观察到的有限候选提出目标假设，再由原节点/页面/动作绑定及测量校验。不能猜CSS，也不能要求所有关系在首次探索前已知。
3. **补充取证与恢复。** 事实仍不足时，从已存在的回执、定向读取和安全下一步中作明确选择，说明缺哪种事实。先复用未失效证据；不得靠“已读过”禁止有新信息或不同查询的合理读取。
4. **子任务收尾与交接。** 由程序依原证据门判断已测、缺陷、未验证或不适用；Jev可建议下一子任务或交回主Agent，不能自行写通过。交给主Agent时提供检查意图、已操作、有效证据位置、待补事实与已失败尝试；交回后仍可在需要时使用同一有界决策能力，不另造第二套浏览器Agent循环。

不强制每个节点都收费调用。程序已有确定答案时直接执行；语义未决时调用Jev；复杂或低置信度时主Agent处理。首批不实现全规则自动规划、任意PRD/Figma解释或通用自治状态机。

## 必须保留的执行约束

- 复用原执行器、权限/取消/预算、scope、action/item、原始测量和报告持久链。Jev建议不越过实际派发前的实时资格复查。
- 原网址扫描已承诺的必查义务独立保留。子任务可以不探索与本目标无关的可选入口，但不能据此核销必查或已选事项；报告分别展示子任务结论与整任务覆盖。
- 不以轮流公平访问无关候选拖离当前子任务。若需区分原任务采样公平性与子任务路径策略，明确最小契约变化，不直接删除全局公平性保护。
- 操作后结果未知时允许原有安全探索、观察与补绑定，不为取得关联重复点击；失效证据、节点替换、导航或取消保持原约束。
- 定义弹窗类别、视口/可见区域、滚动/变换/动画稳定性及允许布局的支持边界；复用既有几何与截图能力。自定义复杂绘制不支持时保留unknown，正常滚动可达内容不能仅凭超出某个矩形误报。缺陷需真实目标绑定和可复核测量，不能把所有大弹层直接判错。
- 从“如何选择动作”到“如何取得验证证据”使用同一子任务记录；决策建议与实际测量分别存储，状态变化触发失效，不让主Agent重新从零寻找已有信息。

## 免费完成条件

采用少量真实浏览器夹具及固定Jev响应，证明完整产品路径，必要场景可合并：

- 仅网址即可触发候选检查；多个无关控件中选对可能弹窗入口，未经选择的可选控件不为凑覆盖被点击。
- 正常弹窗与真实越界/裁切弹窗分别取得正确的测量结论和证据，报告/历史恢复一致。
- 有价值的自定义弹窗或嵌套入口至少一条有界多步路径；首次操作后才能识别结果也能继续取证，而不是强要操作前后置条件。
- 入口预测错误、没有新弹窗、歧义、不支持条件和预算不足均如实结束或有界恢复，不能误报健康或缺陷。
- 主Agent交接含已完成动作与可读证据；同一有效事实复用，确需新读有明确缺口；节点变化等情况允许重新观察。
- 取消、权限/费用边界、过期建议、页面指令注入及既有必查义务不回退。只跑受影响定向验证，不重跑R0/R1全套。

免费证据证明接线和契约，不证明真实Jev识别准确率或收益。开发完成后形成一份精确、可批准的真实产品验证范围、请求/题数和预算；不先另开收益研究，旧40行研究也不重跑。
