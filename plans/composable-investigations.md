# 通用调查程序与未知问题发现

状态：开发中。基线 main `2fcbbc4`；实现分支 `feat/composable-investigations`。本轮不更换模型、框架，不用上一轮 63 个样本证明泛化。

## 目标

Agent 在无专用规则、无类别提示、无目标 selector 的任务中，从公开页面提出假设，生成有界可重放程序，区分正常/异常并提供截图和测量。三种私有评估场景：菜单裁切、操作后反馈不可见、异步布局将关键操作移出视口。核心代码中不得出现这三种类别的路由、工具或判定分支。

## 实现契约

- `page_inspect` 返回有界公共 DOM 几何、文本与状态，涵盖非交互元素。结果描述事实，不能预先标记缺陷。
- `investigation_run` 接收声明式程序：命名目标、measure/wait/act 步骤、基于测量引用的比较断言。没有任意 JS、文件或网络能力；动作复用正式执行器的预算/副作用/取消边界。
- 程序、假设、声明预期、实际测量、执行日志、截图及服务器计算结果一起保存。缺失/歧义/节点替换/不支持/受干预等不计作 false，结论 unknown。
- 事实与规范分离：比较失败只能证明 Agent 声明的有界预期不成立，不能证明任意主观体验或整页异常。报告明确预期作者与范围。
- 临时程序可导出、重新绑定后重放，不自动启用为全局规则；现有 input 快捷探针和规则审批保留。

## 验收

1. 免费：schema 拒绝越界、前向引用/常量自比较；真实 Chromium 测量正反例、缺失/歧义/替换/取消；正常代理行为不误报。程序通过同一运行器，不实现类别判定。
2. 正式工具集成：真实 Server/SDK/浏览器，固定模型只验证注册、预算、持久化、报告与拒绝伪造；不可冒充自主发现。
3. 真实 DeepSeek：相同中性任务与工具，不提供 case/答案/selector/检查方法。全部六个样本保留，记录生成程序、回执、模型请求/费用和失败。不能把手写程序算自主生成。
4. 重放：冻结由模型生成的程序；相同业务正反例重放，仅改变页面 fixture，不改变核心或程序。独立评分器以私有真值判定漏报/误报，不能采用模型自评。
5. 运行 typecheck、format、相关测试及完整回归；记录真实通过范围与限制。失败时诊断并保留旧批次，不隐去失败。
