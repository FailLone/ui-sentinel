# 检查子任务与浏览器并行：首批实现

2026-10-10。用户已批准新开一个Agent并行开发，并要求与应用Agent框架的子Agent委派能力接通。此任务与[弹窗目标驱动检查](../goal-directed-jev/README.md)并行，R1已交付状态不变。

## 完成目标

一个父扫描任务通过真实Agent工具接口创建最多两个子检查任务；各子任务使用独立Playwright BrowserContext，在匿名、可重新进入的页面上确实并行执行。共享总预算与取消，结果和可读证据回到父任务，父报告保留子任务状态及未完成事项。不能只交两个浏览器、Promise.all演示、静态测试worker或独立CLI。

先核对仓库锁定的Mastra版本和可用原生委派能力，优先复用。框架若不能满足共享预算、原执行器或生命周期约束，使用小型委派工具适配已有Agent/工具接口并说明依据，不另造一套Agent框架。子任务可以是确定性程序，只有语义判断需要时调用Jev或专门子Agent，不强制每个检查启动大模型。

## 首版边界

- 父任务最多两个直接子任务、一层委派；不同Context且每个页面内部动作串行。浏览器进程是否共享由原网络/资源所有权决定，不为复用进程破坏隔离。
- 起始状态仅匿名URL、视口、允许的有界前置操作及需核验的公开事实；不承诺完整DOM/JS内存/网络状态克隆。无可靠重建方式则拒绝并发或明确退回串行，不伪称同一状态。
- 新Context安装原网络、DNS、动作许可和证据保护。Context隔离不意味着远端后端状态隔离；本版不支持会修改共享业务数据的操作。
- 父任务预算统一管理，子任务额度从中分配并发预留，模型/Jev/动作/时间按实际记录；不能为每个孩子复制父任务全额预算。取消、截止或停止后不能迟到派发，费用未知按既有策略处理。
- 顶层run串行策略默认保留，先支持一个父run内部有限并行；不要直接把全局队列改成无限并发。原终态/取消仲裁和未知写入保护不得绕过。
- 子任务独立任务ID、浏览器与证据命名空间；测量结论由原执行器产生。父任务不得把子任务失败、pending或取消算作成功；原必查和已选义务不能通过另建子任务绕过。

## 与弹窗Agent的最小接口

并发Agent负责一份小型、版本化公共契约及适配器；弹窗Agent保留自己内部的Jev语义契约和几何模块。公共契约至少表达：

| 部分 | 必需信息 |
| --- | --- |
| 输入 | 父/子任务ID、检查类型和目的、起始URL/视口、前置操作、公开事实/证据引用、权限范围、额度/截止时间 |
| 生命周期 | 提交、进度、查询/等待、取消、终态；幂等任务身份，异常不能丢失 |
| 执行资源 | 已受保护的独立浏览器/原执行器能力、预算与取消句柄；不交任意权限扩大入口 |
| 输出 | 已完成/缺陷/未验证/失败/取消、原action/item/measurement关联、证据引用、未检查事项、实际消耗 |

工具名称和类型以现有代码为准。先写契约与最小适配示例便于并行实现，不为讨论命名多次停工。只读查看另一工作区进度，不修改对方文件、不消费其未提交改动作为冻结依赖。

## 分工与冲突控制

- 弹窗Agent：`src/agent/popup/`、`src/execution/popup/`及其产品策略/入口接线，负责单个弹窗检查闭环。本次不要求它实现调度器或等待并发基础交付。
- 并发Agent：子任务契约、框架委派适配、调度/资源/预算/取消、父子证据汇总，优先新增独立模块。通过小型公共适配器接弹窗执行模块，不复制弹窗决策或测量实现。
- `executor.ts`、`run-queue.ts`、报告与普通入口可能需要共同接点。修改须保持最小，交付明确列出补丁和合入顺序；不得覆盖另一分支或趁机重构全局执行器。必要时并发Agent先完成通用宿主与产品集成接点，待弹窗候选提交后再做一次受限适配复验。
- 同一匿名URL的两个受限检查可使用自有确定性处理器证明调度，但最终交付必须明确“真实弹窗适配已完成”还是“等待具体弹窗提交”；不把占位任务说成全部整合完成。

## 免费验证与交付

在普通产品入口和真实Chromium中，以免费脚本模型主动调用委派工具，证明两个任务的执行时间区间重叠且页面状态互不干扰；任务并行不是两个模型文本声称在并行。

必要定向反例包括：父取消传播、单子任务失败可被父观察、预算同时竞争不超领、过期结果拒绝、证据不串任务、准备失败释放资源、关闭一个子任务不误关另一个、必需事项未完成不得假covered，以及未启用新能力的原串行行为。仅跑受影响验证，不重跑R0/R1全套。已有原实现允许的取消/持久化边界按实际检查，不能宣称已获得新的全面可靠性保证。

交付可运行普通入口、框架委派调用例、公共契约、资源/费用/取消所有权、真实浏览器证据、支持边界、最终SHA及与弹窗分支的合入顺序。免费模型证明工程链路，真实模型是否正确委派仍属后续验证。
