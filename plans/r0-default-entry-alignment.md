## 公开默认承诺

采用版本化 `bounded-ui-sampling-1`，服务端写入每个新 UI 契约/hash，与工作台显示的范围说明共用定义：

| 必需工作 | 冻结与完成规则 |
| --- | --- |
| 入口及实际访问页面的可读观察、适用自动规则 | 复用原证据与规则账本；适用规则 unknown、未完成假设仍阻止 covered。无公开阈值的维度按原契约如实报告 |
| 每个实际访问页面的本地交互样本 | 从该页首批最多 8 个公开候选中选择 **min(3, N)** 个不同控件；N 为该批符合原权限边界的本地候选数，N≤3 时全部纳入。目标缺省仍按此数量执行，不能只选一项就称本轮覆盖 |
| 全程一次合法同源链接检查 | 首次观察到可用候选时登记一项采样义务，由 Agent 从实际候选选择，实际点击并核验落地；没有候选须以持久观察/边界事实证明不适用 |
| 已选/高级声明/已触发的检查事项 | 与默认样本共同保留，完成公开效果测量或有证据的失败；不能删除、降级、换目标或以阳性 probe 代替效果核验 |

Agent 在原决策中依据可选目标和公开观察选择样本，无新增专门的规划模型调用。N>3 时须给出选择依据；选择发生在执行前，分母随即冻结。目标指导选样和效果核验，**不承诺完整编译任意自然语言要求**；目标中未纳入/无法核验的内容在报告中说明，不能仅凭本轮 covered 宣称整个目标已实现。

默认保证的是这批实际控件的公开效果，不只是点击成功或内容仍存在。输入/select 的值与应用按钮的效果分别保留其测量；后置条件仍来自公开 DOM/用户目标，经原验证机制核验。没有可靠后置条件时保留 unverified；指针被拦截的控件仍在样本中，不能因失败排除。预算不足或未知副作用不豁免必需工作，按原 blocked/partial 契约结束。

允许不检查：未选控件、候选截断部分、未访问页面、同一行为的所有参数组合、反复返回和无限动态状态，以及原不支持的登录/写入等能力。每项/类别须保留未检查原因与计数。新状态不会重置该页选样；只有原检查的效果测量、证据调查和必要前置工作继续属于义务。已选目标节点失效保持原未完成事项，不重新抽样替换。

保留现有每页 3 个不同本地控件、最多 8 个候选、最多 3 页/深度 1、全局动作/模型/时限等上限。这里把原“至少一次、最多三项”的开放选样改为“首批冻结至最多三项”的明确默认承诺；不是扩大权限或新建浏览计划。

## 登记与 closing 接线

```ts
UiContractSnapshot.samplingPolicy = {
  revision: 'bounded-ui-sampling-1', candidateLimit: 8,
  localSamplesPerVisitedPage: 3, navigationSamplesPerRun: 1,
  goalMode: 'focus'
};
registerDefaultScope(observation, frozenPolicy); // 原 scope：登记选样义务与观察依据
bindDefaultSelections(currentCandidateIds);    // 原节点身份绑定；实际选项成为 selected 义务
scopeSourcesReady();                          // 默认来源登记闭合 + 高级声明登记完整
```

- 工作台与普通 API 均由服务器安装该默认政策，不提交或伪造 `requiredChecks: []`。高级事项是追加义务，可与实际默认样本去重并计入原额度；不能关闭/替换默认来源或扩大上限。
- 初次有效观察先登记每页的选样数量义务、候选证据与全程导航义务，再接受 Agent 选择。选择不足、未绑定或登记未闭合时，原 scope 仍有 selected/pending 事项，不能收尾。无候选的不适用结论只由执行器从真实观察形成，不因剩余预算少而作出。
- 默认登记使用原候选 item/ref/节点绑定和公开效果验证，不把通用选样转换成用户必须填写的 action/value/selector 脚本。共同来源登记与原测量回执、证明校验共用 `inspection-host`，高级固定后置条件仍按原 API 校验。
- 将当前 `requiredChecks !== undefined` 的 opt-in 开关替换为版本化来源登记状态，使普通入口进入现有 closing。动作/调查/响应结算后的稳定边界，复用同一个 `decideInspectionCompletion`、closing 栅栏、seal 后复判及持久提交；不另造完成标准。
- 可选扩展继续读取实时预算并要求可信成本上界。当前无法提供上界时拒绝并记录未检查范围；不得借扩展准入减少默认数量。取消、未知写入、真实阻断和执行故障优先，F1/工具修正没有叠加续期。
