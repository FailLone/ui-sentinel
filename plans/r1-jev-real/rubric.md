# 四级探索评分量表

实现来源为 `src/agent/decisions/jev-provider/profile.ts` 中的 RUBRIC、READINESS 与可信问题模板。修改它们会改变 adapterRevision，不能复用旧缓存或把新旧成绩拼接。

- relevance：0 明确无关；1 外围弱关联；2 支持目标局部检查；3 直接服务当前局部任务。
- informationGain：0 当前状态已覆盖且无新线索；1 重复可能大/新线索弱；2 有具体线索支持尚未观察的局部状态；3 有明确线索支持任务需要且尚未观察的状态。
- readiness：可评分、信息不足、需要主 Agent 调查。问题之间不依赖其他问题尚未生成的答案。非可评分始终交回，不能通过提高某个候选分数越过它。

候选 ID 只在本地映射使用，可信指令引用程序生成的候选数组索引。页面文字、任务与历史放入公开数据。几何不成为缺陷证据；多种动作效果可以同时出现在已经观察到的历史中。

四级概率经严格验证后计算期望/3；uncertainty 是两个维度归一化熵的较大值。它表示概率分布离散程度，不是已校准的错误率。confidence 门槛默认 0，只适合协议诊断，不能宣称经过校准。

`r1:jev:calibrate` 只接受完整开发批次，免费重放阈值 0/0.25/0.5/0.75/0.9/0.95。先要求交回召回 >=90%、正常误交回 <=15%、首选命中 >=80%；可行项按首选命中、交回召回、较低阈值排序。没有可行项返回 null，不能进入正式评分验证。该工具不改配置、不外发请求，保留集入口直接拒绝。

开发标签是同一实现者根据公开事实写的草稿，仅用于工具开发和量表诊断。独立保留集尚未准备，不能把开发成绩写成独立验收或通用抗注入能力。
