## 2. 确定性验证

验证环境：Node 24.21.0、pnpm 10.17.1；依赖以 pnpm-lock.yaml 为准。

- `pnpm install --frozen-lockfile`：成功。
- `pnpm typecheck`、`pnpm build`：成功。
- `pnpm test`：包含真实 Chromium 的执行/取消/排队/取证测试，以及 Mastra SDK 确定性 provider 契约测试。当前 15 个测试文件、85 项测试通过。
- 真浏览器 0.5 秒与 12 秒延迟：确认测量最终业务反馈，而非立即出现的 Processing。
- `pnpm test:fixtures`：生产 Web/API 和静态靶场启动、私有控制未授权拒绝、源码/答案公共路由不可读、C0–C5 独立条件验证均已成功。记录 `data/verification/fixtures.json`（不进 Git）。
- `pnpm smoke:model`：本机未配置主/视觉模型，明确返回 configuration-missing、非零退出；未调用模型、未静默 mock。
