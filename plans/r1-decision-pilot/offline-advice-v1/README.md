本模式由用户明确授权，与原完整执行准入实验并存。原 `r0-eight-state-20261008/`、其冻结参照及零分母结论保持原样。模式只读取该目录已冻结的8份公开状态；不接收其他任务/样本，不导入历史选择或评价结果，不连接浏览器、执行器、模型传输、数据库或生产默认流程。

## 契约和两条独立结论

`makeAdvicePacket` 校验既有输入、补充公开事实和事项身份，生成 `r1-offline-advice-1 / offline-advice-only` 事实包。程序只读此包；未来如有 Jev 方案，也必须读取**同一完整事实包、同一候选集合和摘要**。目前只产出共享事实包，不生成HTTP请求，不支持原付费CLI直接消费此模式。

输出为候选调查优先序，每项含候选ID、当时公开依据及来源、调查问题、未知字段和执行前检查。`intent=investigate-candidate`；完整执行路径标unknown，directlyExecutable与verifiedProgress均为false。选择 Filters 仅意味着建议调查其状态/命中线索，不证明可点击、存在缺陷或推进成功。

离线入池只要求能识别当前候选，处于已有建议范围和已冻结选中事项内、有允许的inspect调查范围，且未完成或有明确复查理由。已知 permission=no、越界、无inspect范围及无依据的已完成复查排除。unknown 的实时权限、动作时间/美元上界保留原值，不阻断纯离线排序；其他已知前提不成立仍只能调查其原因，不能建议直接操作。当前8状态没有显式复查理由，前缀/观察计数变化不自动重开已完成项。

fill 控件可以作为调查对象，**不是把原生fill改成inspect已执行**；输出单列原生操作缺口。预算是历史事实，不授予新预算。动作效果、新增读取价值及完整执行路径未知，必须列为后续检查；没有合格候选明确交回。缺少效果依据不影响提出有界问题，但阻止“可直接点击/已检查”的结论。

## 固定程序排序规则

1. 已选未完成事项经上述程序过滤形成双方相同候选池；本轮不追加未选事项。
2. 有公开 unrelated 命中样点的调查线索优先；其含义是值得查明，不是更确定存在缺陷。
3. 相同线索级别下，当前快照后对该ref的精确详情读取较少者优先；宽泛selector、全页观察不擅自归属给单个候选。读取次数仅是既有关注程度，不证明重复无用。
4. 按原相对工作量、稳定ID打破平局；不将 estimatedCost=1 当作美元。

所有用于排序的线索在shared-facts里给出，页面文本不会变成指令或权限。原selected/status和截止版本必须一致，未来事件或过期候选拒绝。旧提供方适配器若将来用于本模式，需单独证明它没有丢弃这些事实/候选及建议语义；本轮不扩大到该接线。

分别评价：

- 建议合理性：选中的调查对象是否有参照支持；未知不算错，历史fill/宽泛读取不能映射也不因此剔除状态。
- 完整执行路径：是否已具备许可、前置条件、预算、动作/测量及证据绑定；本轮均未知，不以建议合理性替代。
- 排序竞争：多个候选只是结构条件；还要有可靠、能够区分不同优先建议的参照。可接受集合覆盖全部候选且无可靠偏好顺序时，不能据此评价Jev是否改进排序。

只有可靠的可判别多候选比较存在，才考虑后续授权准备；否则停止，明确无法回答Jev的判断收益、无效读取减少量、执行覆盖或整轮成本。
