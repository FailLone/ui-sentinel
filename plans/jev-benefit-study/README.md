## 有界研究路径

先完成一套可运行、可审阅的免费准备，再提出最小真实批次，不以只有方案文档作为交付。

- 审计 Jev 实际触发条件。区分只有一个候选、明确目标/公平性已决定、公开身份歧义不能安全执行，以及多个合法候选仍待排序。前几类属于调用适用性或安全对照，不能凑进有效收益分母；公开身份歧义不能由评分擅自解除。
- 优先比较两个模式：相同程序基线，和相同程序加 Jev。两者使用相同公开输入、初始状态、动作/时间限制、完成门及评分器；只有排序建议来源不同。主 Agent 单独决策组只有确实回答额外问题时才加入，不默认恢复大矩阵。
- 准备少量可重置的配对状态/路径，包含可区分的结果与平局/无增益对照。先免费证明两种合法选择可能在同一预算内产生不同的可测结果，并确认宿主真的消费排序。若现有宿主永远覆盖评分或根本不触发，先最小修复/明确限制；不能用没有分叉的分母证明收益或无收益。
- 私有预期只给独立评价器，不放入提示、候选文本或产品路由；冻结开发样本与留出样本。可用固定夹具和程序化真值建立参照，无需假装已有独立人工标签。实际公网材料若使用，另标明覆盖边界。
- 离线排序分析与在线闭环收益分别报告。离线一致率只作诊断；产品建议需要原动作、测量、发现和完整报告证据。完整成本含程序和主 Agent 后续调用、Jev提问数量、缓存、恢复与失败；分别记录首响应、完整决策、总路径耗时。
