## 失败归因及本次免费整改

1. **能力/恢复流程缺口（必需整改）**：Agent 在同一调查内先绑定列表行，再点击触发页面替换行节点。调查器保留节点身份、将后置测量置为 unknown 是正确的；但是回执只给 null，没有具体目标失效原因，且仍提示“继续或结束”。Agent 第 3–9 次决策重复查看 DOM/历史/同一结果片段，第 10 次再尝试动作时已经进入 finalizing。并非健康站点缺陷，也不能仅归咎于模型速度。
2. **实现修复**：调查回执新增逐采样/目标的缺失、歧义、替换原因；unknown 明确说明当前检查未验证，以及重新检查公开 DOM、提交新当前状态测量或保留 gap 的恢复途径。旧节点不重新绑定，旧 unknown 和交互义务不自动升级。历史摘要在大参数省略时保留 verdict、状态和有界恢复提示，使用字节限额防止多语言上下文膨胀。
3. **独立发现的校验缺陷**：numeric order 在只有一个匹配节点时可能落入文本相等分支。现在少于两个数值节点一律 unverified；补充单父容器、空集合、正常/异常顺序反例。工具 schema 解释数值条件要求，不加入测试页面名、selector 或答案。
4. **模型行为仍待验证**：修复不能证明模型一定不循环或能完成完整流程。本批失败不能被免费测试改写为通过。
5. **验收器方案缺口与修复**：原 DOM finding 归属使用 `#rows` 字符串过滤，而 `page_inspect` 返回结构 CSS，可能拒绝有效的等价调查。这一逻辑在本批未被走到。批次结束后已改为让独立浏览器实际解析声明的 CSS，核对唯一目标是否为复现中的首行/价格节点，再核对同一测量与断言的值；补充结构 CSS 正例、错行/容器/多匹配/无效 CSS 反例。原批次评分不重算，不以评分修复宣称能力通过。

免费整改是本批结束后的新源码，**不继承旧构建的 C 结果**。新增真实浏览器测试验证动态节点仍 unknown、重新读取当前 DOM 后能区分健康和异常，以及 unknown 不产生 finding；未降低完成、证据归属和写入约束。准确命令、结果、最终提交与 dist hash 见交付包索引。
